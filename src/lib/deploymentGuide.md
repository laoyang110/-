# 问道充值平台部署指南

## 第三方托管服务部署教程

感谢您下载问道充值平台网站代码！本指南将帮助您使用第三方托管服务部署网站，让您的应用可以在互联网上访问。

## 准备工作

在开始部署前，请确保您已完成以下步骤：

1. 下载并解压完整的网站代码包
2. 确保您的代码已通过本地测试，可以正常运行
3. 注册一个第三方托管服务账号（推荐以下服务之一）

## 推荐的托管服务

### 1. Netlify (推荐新手使用)
- **优点**：免费方案足够使用，操作简单，自动部署
- **缺点**：高级功能需要付费

### 2. Vercel
- **优点**：对React应用支持极佳，免费方案功能丰富
- **缺点**：自定义域名需要升级付费方案

### 3. GitHub Pages
- **优点**：完全免费，与GitHub无缝集成
- **缺点**：配置相对复杂，不支持服务端功能

### 4. 阿里云/腾讯云
- **优点**：国内访问速度快，服务稳定
- **缺点**：需要备案，免费额度有限

## 部署步骤（以Netlify为例）

### 步骤1：准备代码
1. 将代码上传到GitHub/GitLab/Bitbucket等代码仓库
2. 确保项目根目录包含`package.json`文件

### 步骤2：注册并登录Netlify
1. 访问[Netlify官网](https://www.netlify.com/)并注册账号
2. 使用GitHub账号登录（推荐，方便后续集成）

### 步骤3：创建新站点
1. 点击"New site from Git"按钮
2. 选择您的代码仓库
3. 配置构建设置：
   - **构建命令**：`pnpm build` 或 `npm run build`
   - **发布目录**：`dist/static`

### 步骤4：部署网站
1. 点击"Deploy site"按钮开始部署
2. 等待构建和部署完成（通常需要1-3分钟）
3. 部署成功后，Netlify会提供一个随机域名，您可以通过该域名访问网站

### 步骤5：自定义域名（可选）
1. 在项目设置中找到"Domain settings"
2. 可以使用Netlify提供的免费子域名，或添加自己的域名
3. 根据指引完成域名解析设置

## 部署常见问题解决

### 构建失败
- 确保本地可以成功运行`pnpm build`命令
- 检查项目依赖是否完整，可尝试删除`node_modules`和`pnpm-lock.yaml`后重新安装依赖

### 页面空白或资源加载错误
- 检查部署时的"发布目录"是否设置为`dist/static`
- 确保路由使用的是HashRouter而非BrowserRouter（静态部署推荐）

### 访问速度慢
- 考虑使用CDN服务
- 优化图片和静态资源大小

## 部署检查清单

- [ ] 确保所有环境变量已正确配置
- [ ] 测试网站在不同浏览器中的兼容性

- [ ] 设置自定义域名（如需要）
- [ ] 配置HTTPS证书（大多数托管服务会自动提供）

## 进阶部署选项

- 使用Docker容器化应用并部署到云服务器
- 设置CI/CD流水线实现自动测试和部署
- 配置CDN加速静态资源访问

如有任何部署问题，建议参考您选择的托管服务的官方文档或联系其客服支持。
